# Cybersecurity Awareness Chatbot - ST10435412

An interactive command-line application built in C# to educate South African citizens on common online safety protocols.

## Prerequisites
- .NET SDK 8.0 or newer installed on your local operating system.

## Setup Instructions
1. Place a short recorded audio file named `welcome.wav` directly into the project compilation output build folder (`/bin/Debug/net8.0/`).
2. Open your command terminal within the project directory.

## Running the Application
Execute the following commands:
```bash
dotnet restore
dotnet build
dotnet run
```
